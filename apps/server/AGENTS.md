# apps/server — AGENTS.md

The Cloudflare Worker. Root rules in [/AGENTS.md](../../AGENTS.md) apply.

## Layout

```
src/
  index.ts              Entry: default export (router) + every bound Durable Object class. Exports only.
  http/router.ts        HTTP routing. Decides which user's agent a request reaches.
  auth/google.ts        Google OAuth and the signed session cookie
  agents/assistant.ts   Think assistant (Durable Object): model, prompt, tools, callables
  agents/pi.ts          Pi-harness assistant (Durable Object)
  agents/reminders.ts   Reminder scheduling shared by both agents
  agents/prompt.ts      Persona and memory formatting
  integrations/         Third-party channels (telegram.ts: per-user bots + TelegramRoutes DO)
  tools/                Capabilities the agents call (browser, code runner, sandbox DO)
wrangler.jsonc          Bindings, Durable Objects, migrations, routes
env.d.ts                Generated by `npm run types` — never edit by hand
```

## Rules

- **Routing is the security boundary.** The Worker, not the client, picks the
  agent instance (`google:<sub>`). Never add a generic `/agents/*` route or
  let a client choose an instance name.
- **New Durable Object class**: export it from `src/index.ts`, add the
  binding and a new `migrations` tag in `wrangler.jsonc`, then
  `npm run types`.
- **New path the Worker must handle**: add it to `assets.run_worker_first`
  in `wrangler.jsonc` (otherwise the SPA fallback answers it) and, if a
  client calls it, to `AUTH_ROUTES` / `HARNESSES` in `@cot/shared`.
- **New callable**: add it to `AssistantRpc` in `@cot/shared` first, then
  implement it with `@callable()`. Validate every argument; it comes from the
  network.
- **New tool**: put the capability in `src/tools/<name>.ts` (pure function of
  `env` + input) and register it in `getTools()`. Tools that change state
  outside the chat (commands, file writes) need approval; add them to
  `NEEDS_APPROVAL` so they're withheld from Telegram turns.
- **New integration** (Slack, email, …): `src/integrations/<name>.ts`, with
  secrets stored in the user's agent, never in the client.
- Return tool errors as text (`String(error)`) so the model can recover;
  throw from callables so the client sees a rejected promise.
- The Worker is compiled without the DOM lib. Code that runs in a browser
  page (Puppeteer `evaluate`) must declare the globals it reads.
