# ADR 0002: Bun as the package manager

- Status: accepted
- Date: 2026-10-27
- Supersedes: the npm choice in [ADR 0001](0001-monorepo-layout.md)

## Context

ADR 0001 kept npm because it was already in use. We prefer Bun for its
faster installs and `bun run --filter` for workspace scripts.

## Decision

1. **Bun workspaces** with the same `apps/*` / `packages/*` layout. The
   lockfile is `bun.lock`; internal dependencies use `workspace:*`.
2. **Hoisted linker** (`bunfig.toml`). Tailwind's `@source` paths in
   `apps/web` point at the root `node_modules`, which Bun's default isolated
   linker would not populate.
3. **Lifecycle scripts** run only for packages in `trustedDependencies`
   (the same set npm's `allowScripts` allowed).
4. **Node.js stays installed.** Bun is the package manager and script
   runner; Vite, Wrangler and the other CLIs still run on Node.

## Consequences

- Contributors install Bun (version pinned in `packageManager`).
- CI uses `oven-sh/setup-bun` and `bun install --frozen-lockfile`.
